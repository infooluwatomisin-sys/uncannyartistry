# Uncanny Artistry | Homepage Concept 02

A static, dependency free homepage (HTML, CSS, JavaScript). No build step.

## Deploy to a new Vercel project

1. Put this folder in a new Git repository, or run `vercel` inside it.
2. In Vercel choose "Add New Project" and import the repository.
3. Framework Preset: Other. Build Command: none. Output Directory: leave blank (root).
4. Deploy.

## Missing assets (photography)

No product photography exists yet, so the page uses illustrative studio plates drawn in SVG.
Drop real photos into an `images/` folder using these exact names and they replace the plates automatically. No code changes needed.

| File | Used for | Suggested size |
| --- | --- | --- |
| images/hero.jpg | Hero scene with tumbler, mug and bottle | 1600 x 1920 |
| images/tumbler.jpg | Tumblers card | 1200 x 1500 |
| images/mug.jpg | Mugs card | 1200 x 1500 |
| images/bottle.jpg | Bottles card | 1200 x 1500 |

Use JPG or WebP renamed to .jpg, compressed under 300 KB each.
Photography should use neutral studio backgrounds, concrete surfaces and soft directional light, with the artwork as the focal point.

## Notes
